# Package Management: Debian Systems
## There are two package management programs that are used when downloading files:
- dpkg (deep package)(Deep package is not commonly used)
- apt (This command is called 'advanced package tool. It is a command-line tool used to install, update, upgrade, and remove software packages.)
  - E.g: sudo apt update
         sudo apt install nginx
         sudo apt upgrade
         sudo apt remove nginx
- sudo means "superuser do". Its purpose is to let a normal user run a command with administrator (root) privileges.
- Use which to check if something is installed

# Red Hat Package Manager (RPM) Systems
- This is a package-management system used primarily by Red Hat-based distributors
- YUM is a package manager used on Red Hat based Linux distributions. It is similar to apt, it finds, downloads, installs, updates, and removes software.
